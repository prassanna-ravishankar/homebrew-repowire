# Homebrew Repowire

Official Homebrew tap for [Repowire](https://repowire.io), the mesh network for
AI coding agents.

## Install

```sh
brew install prassanna-ravishankar/repowire/repowire
repowire setup
```

The formula is published from Repowire's checksum-pinned native release
archives. It will become available with the first native release, `v0.18.0`.

You can also tap the repository explicitly:

```sh
brew tap prassanna-ravishankar/repowire
brew install repowire
```

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "prassanna-ravishankar/repowire"
brew "repowire"
```

## Documentation

See the [Repowire documentation](https://docs.repowire.io) for setup and usage.
