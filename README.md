# Prassanna-ravishankar Repowire

## How do I install these formulae?

`brew install prassanna-ravishankar/repowire/<formula>`

Or `brew tap prassanna-ravishankar/repowire` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "prassanna-ravishankar/repowire"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
